# AGENTS.md — google_auto_translate

## What this is
Client-side auto-translation example using the Google Translate JavaScript API. Hides the toolbar, sets translation via cookies, detects language from subdomains.

## Stack
- HTML5 / JavaScript
- Google Translate JavaScript API

## Run
Serve `public/` via any static web server.

## Structure
- `public/index.html` — demo page
- `public/js/` — JavaScript (translate logic, cookie handling)
- `dockers/` — Docker hosting setup
